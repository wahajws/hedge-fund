# AI Governance

Qwen is used only for:

- summarization
- interpretation
- classification
- report drafting
- workflow coordination

Qwen must not:

- invent market values
- calculate portfolio risk
- fabricate source IDs
- bypass approval gates
- create trade instructions without human review

Every AI output is validated against a structured schema and linked to source IDs, prompt version, model version, workflow ID, agent log ID, and audit events.
