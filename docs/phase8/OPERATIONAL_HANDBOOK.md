# Operational Handbook

Morning routine:

1. Check `/api/ops/readiness`.
2. Review integration health.
3. Run ingestion if feeds are stale.
4. Run morning macro intelligence.
5. Review executive alerts.
6. Clear or escalate pending approvals.
7. Generate CIO Morning Brief.

Daily monitoring:

- stale feeds
- failed ingestion items
- Qwen latency and schema guardrails
- approval backlog
- workflow completion time
- executive alert volume
